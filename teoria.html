Teoría: direccionamiento IP

Guía de repaso para entender una dirección IPv4 antes de usar las calculadoras. Si algo no queda claro, prueba el ejemplo en la calculadora de subneting.

1. ¿Qué es una dirección IP?

Una dirección IPv4 es un número de 32 bits que identifica a un dispositivo dentro de una red. Para leerla con comodidad se divide en 4 octetos (grupos de 8 bits) escritos en decimal y separados por puntos. Cada octeto puede valer entre 0 y 255.

La dirección tiene siempre dos partes: la parte de red, que es igual para todos los equipos de la misma red, y la parte de host, que distingue a cada equipo. Qué trozos son de red y cuáles de host lo decide la máscara (Apartado 3).

192.168.1.1 → 11000000.10101000.00000001.00000001
red = 192.168.1  ·  host = .1  (con máscara /24)

2. Clases de direcciones (A–E)

El direccionamiento clásico o con clases deduce el tamaño de la red a partir del primer octeto. La clase determina cuántos octetos pertenecen a la red y cuántos al host.

ClasePrimer octetoBits inicialesUso
A1 – 1260Redes muy grandes

E240 – 2551111Experimental

La dirección 127.x.x.x está reservada para loopback (el propio equipo) y no se usa como red. Las clases A, B y C se dividen en subredes; D y E tienen usos especiales.

3. La máscara de subred y la notación CIDR

La máscara de subred es un número de 32 bits con los unos agrupados a la izquierda y los ceros a la derecha. Marca con 1 la parte de red y con 0 la parte de host. Siempre se escribe en binario como 111...111000...000: los unos y los ceros no pueden alternarse.

En notación CIDR basta con el prefijo /n, donde n es el número de bits a 1. Así, /24 equivale a la máscara 255.255.255.0.

4. Subneting: dividir una red

Hacer subneting es partir una red en varias subredes más pequeñas. Para ello se toman prestados bits de la parte de host y se añaden a la parte de red: cada bit prestado duplica el número de subredes y reduce a la mitad los hosts de cada una.

  • Número de subredes = 2^bits prestados.
  • Direcciones por subred = 2^bits de host.
  • Hosts útiles = 2^bits de host − 2 (se descuentan la dirección de red y la de broadcast).
  • El número mágico es 256 − último octeto de la máscara y marca el salto entre subredes.

Ejemplo: a una empresa le asignan la red 200.3.25.0/24 (clase C, 254 hosts útiles) y necesita 8 subredes. Como 2^3 = 8, hay que tomar prestados 3 bits, así que la máscara pasa a /27 = 255.255.255.224. Cada subred tendrá 2^5 = 32 direcciones, es decir 30 hosts útiles, y el salto entre subredes es 256 − 224 = 32.

5. Direcciones privadas y públicas

Las direcciones públicas son únicas en Internet. Las privadas se usan dentro de redes locales y se repiten en miles de organizaciones; un router no las enruta hacia Internet. El documento RFC 1918 reserva tres bloques:

BloqueRangoMáscara (CIDR)Clase
24 bits10.0.0.0 – 10.255.255.25510.0.0.0/8A
20 bits172.16.0.0 – 172.31.255.255172.16.0.0/12B
16 bits192.168.0.0 – 192.168.255.255192.168.0.0/16C

El rango 169.254.0.0/16 se reserva para la autoconfiguración (enlace local) cuando un equipo no obtiene dirección por DHCP. Para que una red privada salga a Internet se usa NAT: el router traduce las direcciones privadas a su dirección pública.

El ejemplo 192.168.1.1 de la portada es una dirección privada: sirve dentro de la red local, no en Internet.
