# MEMORY.md

## Project Overview
Static educational site about IP networks (Redes IP) plus classroom tools (generador de contraseñas, tareas, notas, agenda). Pure HTML/CSS/JS — no build step, no package manager, no framework, no tests, no CI. Must be served over HTTP (`python -m http.server`): navigation uses `fetch()` and breaks on `file://`.

## Architecture
- `index.html` is the **only real entry point** and the only place with `<link>`/`<script>` tags (Bootstrap CDN + `scripts/*.js` + `css/*.css`).
- `inicio.html`, `teoria.html`, `clases.html`, `subneting.html`, `pass.html`, `tareas.html`, `notas.html`, `agenda.html` are **pure-markup fragments** (no doctype/head/body/link/script) injected into `#cuerpo` by `cargarFragmento()` in `scripts/redes.js`. `teoria.html` is the theory tutorial (IPv4 basics, classes A–E, mask/CIDR, subneting with the `200.3.25.0/24 → /27` example, private/public addresses per RFC 1918, and a "Más lectura" list of external links). Its menu link ("Teoría") replaced the old paid Platzi link.
- **Key gotcha:** `<script>` tags injected with `innerHTML` never execute. That is why `cargarFragmento()` calls `inicializarFragmento(archivo)` after injection, which runs the per-fragment init function: `iniciarPass()`, `iniciarTareas()`, `cargarNotas()`, plus `prepararValidacionIP()`. New fragment with JS → register it there.
- Tool scripts must not run DOM code at load time (elements do not exist yet). Inline `onclick` handlers in fragments need their functions to stay global.
- `scripts/`: `redes.js` (IP utilities, class detection, subneting calculators, tutor mode, loaders), `scriptpass.js` (password generator + copy-to-clipboard with a `navigator.clipboard` → `execCommand('copy')` fallback for insecure contexts, i.e. http on the LAN), `scriptTareas.js`, `notas.js`.
- **Persistence:** the tools save data in `localStorage` as JSON — keys `contrasenas` (`[{login, password}]`), `tareas` (`[{id, texto, completada}]`) and `notas`. Pattern: `leerX()`/`escribirX()` helpers with `try/catch` (private mode/quota), init function reloads from storage and repaints after every mutation. Stored passwords are plain text in the browser (classroom use only — noted in the UI). Rendering uses `createElement`/`textContent`, never `innerHTML` with user data (password charset contains `<`/`>`).
- `css/`: unified dark "NOC" theme. `tema.css` holds design tokens (`--red-*`, including the `--red-gradient` cian→teal accent) and overrides Bootstrap CSS variables (`data-bs-theme="dark"` on `<html>`, cyan accent, fonts **IBM Plex Sans** body + **IBM Plex Mono** data via `--red-font-body`/`--red-font-mono`); `estilos.css` is the layout (navbar, footer, agenda) + the **home portada**: a two-column hero (`.hero-redes`) with the IP-address signature (`address-signature`, octeto blocks), data chips (`.hero-chips`/`.chip`) and a hand-drawn inline SVG network illustration (`.hero-art`) whose data-flow packet animates along a path (offsets respected; disabled by the global `prefers-reduced-motion` rule), plus the "Explora el sitio" feature cards (`.feature-card`, `.icon-circle`, `.card-link`, `.tool-pill`) and the three-step "¿Por dónde empiezo?" guide (`.step`/`.step-num`). `stylepass.css`, `tareas.css`, `notas.css` are scoped under `.vista-pass` / `.vista-tareas` / `.vista-notas` (their fragment wrapper) so `body`/`button`/`input`/`.container` rules don't leak site-wide. Layout uses two systems: `.panel` (slab, elevated — interactive tools) and `.field` (flat, hairline — explanatory content). `normalize.css` was removed (Bootstrap Reboot covers it). The whole home portada (hero + cards + guide) on `inicio.html` is duplicated as the initial content of `#cuerpo` in `index.html` and must stay in sync. Table headers are sentence case (no uppercase); `:focus-visible` and `prefers-reduced-motion` are handled in `tema.css`.
- Subneting is **classful**: classes A/B/C only, contiguous masks ≥ the class default, at least 2 host bits. Listings use 32-bit arithmetic (no manual carry).

## Dependencies
- Bootstrap 5.3.8, Bootstrap Icons and Google Fonts **IBM Plex Sans** + **IBM Plex Mono** (CDN). jQuery is not used.

## Conventions
- All UI text, comments, and alerts are in **Spanish**. Maintain this for any new content.
- **Language rule:** everything (code comments, docs, commit messages, chat replies) is written in **Spanish**; English only when strictly unavoidable (technical names, identifiers, third-party terms). No other languages.
- No build tools, no package manager, no test suite, no CI pipeline.
- `.agents/` and `skills-lock.json` are local AI-skills config installed by `autoskills` (accessibility, seo, frontend-design, deploy-to-vercel). They are **git-ignored** (see `.gitignore`): they are not part of the site and can be regenerated with `npx autoskills`.
